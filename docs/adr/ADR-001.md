# ADR-001 – Stack decidida

## Status

Accepted

## Contexto

Para garantir consistência tecnológica e facilitar a colaboração entre front‑end e back‑end, foi definido um stack baseado em TypeScript, React, Vite, NestJS, Prisma e MySQL. A escolha segue as diretrizes de usar tecnologias amplamente adotadas, bem suportadas por IA e com boa documentação.

## Decisão

- **Linguagem:** TypeScript (strict) em todo o monorepo.
- **Front‑end:** React + Vite + Tailwind CSS.
- **Back‑end:** Node.js + NestJS.
- **Banco de dados:** MySQL (Docker Compose).
- **ORM:** Prisma.
- **Monorepo:** pnpm workspaces com `apps/web`, `apps/api`, `packages/shared`.
- **CI/CD:** GitHub Actions para lint, type‑check, testes, build e geração de grafo.

## Consequências

- **Positivas:** Ferramentas bem documentadas, tipos compartilhados via `packages/shared`, fácil integração CI.
- **Negativas:** Necessidade de rodar Docker para MySQL localmente; aprendizado de Prisma para quem não conhece.
