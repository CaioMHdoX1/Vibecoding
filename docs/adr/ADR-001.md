# ADR-001 – Stack Choice

- **Title**: Escolha da pilha tecnológica
- **Date**: 2026-11-12
- **Status**: Accepted
- **Context**: Necessário definir as tecnologias que suportarão o desenvolvimento do e‑commerce de bonsai, garantindo clareza, consistência e adotando ferramentas estáveis e amplamente suportadas.
- **Decision**: Adotar a pilha abaixo:
  - **Linguagem**: TypeScript (strict mode)
  - **Frontend**: React com Vite, Tailwind CSS
  - **Backend**: NestJS (Node.js) + Prisma ORM
  - **Banco de dados**: MySQL (via Docker Compose)
  - **Monorepo**: pnpm workspaces (`apps/web`, `apps/api`, `packages/shared`)
  - **Containerização**: Docker Compose para subir MySQL, API e Web em um único comando
  - **CI/CD**: GitHub Actions (lint, testes, build)
- **Consequences**:
  - *Positivos*: Ferramentas modernas, tipagem forte, grande comunidade, fácil integração com IA, suporte a monorepo.
  - *Negativos*: Necessita conhecimento de TypeScript avançado e configuração inicial de Docker.
- **Alternatives considered**:
  1. Usar JavaScript tradicional (perde tipagem).
  2. Usar Next.js em vez de Vite (mais complexo para MVP).
  3. Usar Express.js + Sequelize (menos estrutura que NestJS).

*Esta decisão segue as diretrizes de YAGNI, reutilização e simplicidade (pony‑tail).*
