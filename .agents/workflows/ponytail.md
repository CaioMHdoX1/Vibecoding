# Workflow: ponytail

Apply the ponytail skill to review code, eliminate bloat, or audit for unnecessary abstractions and dependencies.

- If invoked as `/ponytail review`, perform a concise anti-bloat review on the current diff or recent changes.
- If invoked as `/ponytail audit`, analyze the codebase for redundant utilities, bloated wrappers, and unneeded dependencies.
- Follow the rules defined in `.agents/skills/ponytail/SKILL.md`.
